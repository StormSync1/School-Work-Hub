# School Work Hub

School Work Hub is a simple website made to help students keep all their schoolwork in one place.

## Features

* Homework tracker
* Class organization
* Calendar
* Grade tracking
* Study timer
* Notes
* Goals
* Achievements
* Useful school tools
* Dark mode

## Why I Made It

I made School Work Hub because I wanted one simple place to keep track of schoolwork instead of having everything spread across different websites and apps.

## Built With

* HTML
* CSS
* JavaScript

## Status

This project is still being worked on, and more features will be added over time.
