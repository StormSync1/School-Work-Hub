# Build the APK

1. Open the `phone-project` folder in Android Studio.
2. Allow Gradle sync and install any SDK component Android Studio requests.
3. Select `app` and choose `Build > Build Bundle(s) / APK(s) > Build APK(s)`.
4. The debug APK will be at `app/build/outputs/apk/debug/app-debug.apk`.

The project uses Android SDK 35, minimum SDK 24, and application ID `com.schoolworkhub.app`.
