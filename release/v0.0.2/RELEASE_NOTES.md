# School Work Hub 0.0.2

## New Features

- Added a PC Windows installer and Android Studio phone project.
- Added PC landscape layout and a responsive mobile layout.
- Fixed mouse-wheel and finger scrolling.
- Added Android notifications with notification permission support.
- Added language selection with English, Tagalog, Spanish, French, German, and Portuguese core translations.
- Added 12-hour and 24-hour clock settings.
- Added a first-time welcome tutorial.
- Added Due Soon dashboard sections for today, tomorrow, and this week.
- Added grade calculator and class dashboards.
- Added missing-work tracking, streaks, XP, levels, daily challenges, and weekly challenges.
- Added achievements, XP Shop rewards, combo progress, and completion celebrations.
- Added Pomodoro and custom study timers.
- Added flashcards, practice-question storage, mistake tracking, and study-time tracking.
- Added calendar entries, exam countdowns, heatmap progress, pinned assignments, favorites, one-click completion, and recycle-bin recovery.
- Added device-local saving so each device keeps its own Schoolwork Hub data.
- Added Android Studio build configuration and APK instructions.

## Included Downloads

- Windows installer: `Schoolwork Hub Setup 0.0.2.exe`
- PC source package: `Schoolwork-Hub-PC-v0.0.2.zip`
- Android Studio project: `Schoolwork-Hub-Phone-v0.0.2.zip`

## Android Build

Open the extracted `phone-project` folder in Android Studio and build the debug APK. The APK will be at `app/build/outputs/apk/debug/app-debug.apk`.
